# ☀️ Solar Plant Chatbot

An intelligent, interactive Streamlit chatbot and analytics assistant for solar power generation datasets. It combines **deterministic statistical calculations** on real dataset metrics with **generative AI reasoning** powered by the **Google Gemini API** and local **Ollama** models.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/deploy?repository=NishantJLU/Solar-chatbot&branch=main&mainModule=streamlit_app.py)
![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)
![Gemini API](https://img.shields.io/badge/AI-Google%20Gemini%20API-orange.svg)

## 🌟 Key Features

- **⚡ Instant Dataset Insights**: Directly answers queries about statistics (mean, maximum, minimum, median, sample rows, and summary tables) without hallucinating numbers.
- **🤖 Powered by Google Gemini**: Uses Google's latest **Interactions API** (`gemini-3.8-flash`, `gemini-flash-latest`, `gemini-2.5-flash`) for conceptual explanations and solar engineering queries.
- **💻 Dual Engine (Cloud & Local)**:
  - **Cloud:** Connects to Google Gemini API via Streamlit Secrets or sidebar key.
  - **Local:** Automatically falls back to local **Ollama** (`gemma4:e2b`) if running offline.
- **📊 Dataset Inspection Sidebar**: Overview of records (5,000 data points), column definitions, model switcher, and one-click chat clearing.
- **🚀 One-Click Cloud Deployment**: Pre-configured for deployment on **Streamlit Community Cloud**.

## 📊 Dataset Schema

The application is bundled with `solar_plant_generation_dataset.csv` containing 5,000 operational records:

| Column Name | Unit | Description |
|---|---|---|
| `timestamp` | YYYY-MM-DD HH:MM | Measurement time interval |
| `power_generation_kw` | kW | Power generated by solar plant |
| `solar_irradiance_wm2` | W/m² | Solar radiation reaching panels |
| `ambient_temperature_c` | °C | Surrounding air temperature |
| `panel_temperature_c` | °C | Solar panel surface temperature |
| `cloud_cover_percent` | % | Cloud cover percentage |

## 🚀 Quick Start (Local Setup)

### 1. Clone the Repository
```bash
git clone https://github.com/NishantJLU/Solar-chatbot.git
cd Solar-chatbot
```

### 2. Set Up Virtual Environment & Dependencies
```bash
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Run the App
```bash
streamlit run streamlit_app.py
```
Open [http://localhost:8501](http://localhost:8501) in your browser.

*(Optional)* If you want to use local Ollama instead of Gemini, install [Ollama](https://ollama.ai/) and run:
```bash
ollama run gemma4:e2b
```

## ☁️ Deployment on Streamlit Community Cloud

1. Fork or push this repository to your GitHub account: `https://github.com/NishantJLU/Solar-chatbot`
2. Go to [share.streamlit.io](https://share.streamlit.io/) and click **"New app"**.
3. Select:
   - **Repository:** `NishantJLU/Solar-chatbot`
   - **Branch:** `main`
   - **Main file path:** `streamlit_app.py`
4. Click **Deploy!**

### Adding your Gemini API Key in Secrets
1. In your deployed app, click **Settings** (or the `...` menu in the lower-right corner) ➔ **Secrets**.
2. Add your free key from [Google AI Studio](https://aistudio.google.com/):
   ```toml
   GEMINI_API_KEY = "your-actual-gemini-api-key-here"
   ```
3. Click **Save**. The app will reload and your AI responses will be active.
